# PortMaster packaging

This directory holds the PortMaster packaging for STACKFALL. The build
writes nothing here yet.

Planned contents, added in milestones M4 and M5:

- `Stackfall.sh` — launcher script built from the current official
  PortMaster template.
- `port.json` — PortMaster package metadata.
- `gameinfo.xml` — PortMaster game information.
- `README.md` — package readme for players.

Read `docs/SPEC.md` sections 10.2 to 10.4 for the AArch64 build
environment, the install layout under `/roms/ports`, and the release
archive.
