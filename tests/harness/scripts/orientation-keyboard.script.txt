# Orientation-keyboard stage one (T068, docs/AGENT_TESTING.md; the staged
# portrait session of T055 grown into the same-session turn): a landscape
# session walks to the seventh OPTIONS row, ORIENTATION, and selects it with
# a key held across the turn - key left, which holds move-left in landscape
# and is the logical up direction that hard drops in portrait. The turn
# applies inside the tick that consumed the select edge, so the held level and
# every pending edge must be gone before the next tick: no later tick may
# carry a gameplay bit until the script presses again, and the release that
# follows maps through the portrait table and changes nothing.
#
# The rest of the stage plays the turned session on the rotated keyboard
# table - the title walk, a round whose key up moves right and key down moves
# left, Z clockwise, the logical up of key left hard dropping, and the pause
# overlay on the rotated menu roles - then turns back to landscape, turns to
# portrait a second time, and quits through the portrait table, so the saved
# preference the relaunch of stage two reads is portrait. A `wait` follows
# every check, so no record carries the tick of the input that comes after
# it.
