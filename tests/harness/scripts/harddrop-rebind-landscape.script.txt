# T87 stage one, landscape (docs/AGENT_TESTING.md): the hard-drop trigger
# leaves Up on the developer virtual controller, seed 20261103. A first round
# pins the T067 default and its sensitivity rules - a light stick reading
# inside the deadzone drops nothing, a D-pad-up press drops once, and a full
# stick-up deflection held across many ticks drops exactly once, because the
# axis path is edge-triggered behind the deadzone. The customization screen
# then rebinds HARD DROP to the face button X, to the right shoulder R1 - the
# shoulder the T066 list could not reach, because the left one is Hold's
# spare - and, on the keyboard half of the same row, to D. A second round on
# the rebound tables proves the freed D-pad up, the freed stick-up arm, and
# the X the second capture replaced all carry nothing, while R1 and D hard
# drop. A `wait` follows every check, so no record carries the tick of the
# input that comes after it.
